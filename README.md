# WordPress Code Snippets

## 1. Activation Fatal Error Logger (`activation-fatal-logger.php`)

یک Must-Use Plugin برای ردیابی و ثبت خطاهای مهلک (Fatal Errors) که در زمان فعال‌سازی افزونه‌ها در وردپرس رخ می‌دهند.

### ویژگی‌ها:
- **تشخیص دقیق فرآیند فعال‌سازی**: با استفاده از سیگنال‌های داخلی هسته وردپرس (`activate_plugin` و `WP_SANDBOX_SCRAPING`) برای تشخیص انواع فعال‌سازی‌ها (تکی، دسته‌جمعی / Bulk، ایجکس، REST API و WP-CLI).
- **جلوگیری از لاگ تکراری**: ایگنور کردن فریم `error_scrape` در `plugins.php` جهت جلوگیری از دو بار لاگ شدن خطای یکسان.
- **ثبت در فایل ایمن**: ذخیره لاگ در فایلی با گارد امنیتی `<?php exit; ?>` تا حتی در صورت در دسترس بودن فایل از طریق وب، اطلاعات نشت نکند (`wp-content/activation-fatal-errors.log.php`).
- **اعلان در پیشخوان (Admin Notice)**: نمایش خطای رخ‌داده در پیشخوان مدیریت برای کاربرانی که دسترسی مدیریت دارند همراه با امکان Dismiss.
- **سازگار با چندسایته (Multisite)**: پشتیبانی کامل از Network Activation و تنظیمات شبکه.

### نحوه نصب و استفاده:
1. فایل `activation-fatal-logger.php` را در مسیر `wp-content/mu-plugins/` در هاست یا محیط محلی خود قرار دهید (در صورت عدم وجود پوشه `mu-plugins`، آن را بسازید).
2. این افزونه به صورت خودکار فعال شده و هرگونه خطای فعال‌سازی را لاگ خواهد کرد.
3. در صورت تمایل به تغییر مسیر فایل لاگ، می‌توانید ثابت زیر را در `wp-config.php` تعریف کنید:
   ```php
   define( 'AFL_LOG_FILE', '/path/outside/webroot/afl.log.php' );
   ```
